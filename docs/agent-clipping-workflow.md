# Reliable clipping through Rewind tools

External agents already connected to Rewind use MCP at `/mcp`. ACP is Rewind acting as a client to a configured agent process; it is not an HTTP endpoint for an external agent to call. The browser drawer has its own authenticated routes. A2A inbound tasks are available at `POST /api/a2a` with the same bearer MCP scopes.

1. Read `get_clipping_workflow`. Use a known video, channel, or creator as the search scope. A guest does not need to own a channel or have a creator record. Uploader metadata is not speaker attribution. Named episodes plus “related/recent/engaging clips” means find something they talked about across multiple weeks or shows (`get_context_windows`, `get_related`, `list_channel_videos`), then search those terms so the clips hang together. Prefer playable full episodes over clip-channel recuts.
2. Search with `find_clip_candidates(video_id=...)` after localizing an episode. `queries` are alternatives. For required topics, use `query_groups: [["Callen", "Callan"], ["Tesla", "\"test lid\""]]`. Each group must match within the nearby transcript passage; aliases within a group are alternatives. Set `context_seconds` to the desired discussion span, up to 300 seconds. Inspect returned evidence before assigning a speaker or choosing a clip. `candidate.segment.start/end` is a spoken beat around the evidence timestamp, not the context window; do not copy window bounds.
3. When a transcript is unavailable on an archived file, `get_transcript` returns available languages/coverage, existing transcription jobs, and a recovery operation. `enqueue_transcribe(video_id)` queues the full video. Optional paired `start` and `end` request at most 1800 seconds of source audio. Poll `get_transcription_status(job_id)`; missing models are reported as waiting states and are never implicitly downloaded. Missing related episodes: `index_url` / `index_channel_catalog` for captions only, then poll `get_index_status`.
4. Range results are reusable, indexed, and use absolute source times. `complete:false` and `coverage_ranges` identify the portions transcribed. Range work never replaces an existing full transcript. If no transcript exists, a contact sheet can locate an approximate range first. No shell access to archive files is needed.
5. Refine the selected beat with `suggest_clip_boundaries` only if `get_transcript` shows the claim continues. Save a compilation plan without `merge_nearby` (it glues nearby beats), then create an editable Stitch project. Preserve editorial order unless chronological order was requested. Return its `web_path`, evidence and coverage limitations.

The Callen/Callan and Tesla/test-lid examples are explicit query alternatives and regression cases, not global substitutions. A title or visual cue can identify an episode but does not prove a spoken quote. Existing `get_clipping_workflow` and its MCP prompt provide this guidance to every connected agent without requiring a provider-specific skill installation.

Verification: `make test` covers grouped query semantics and source-time range merging. `make integration-test` exercises the MCP transcription queue/status, idempotent enqueue, missing-transcript recovery, single-video scope, cross-cue topic matches, catalog uploader restrictions, complete-transcript preservation and duration recovery on the disposable database. Actual ASR quality still depends on the installed model and source audio.
